راهنما How to Use

در ۳ قدم ساده In 3 simple steps

۱. قالب را دانلود کنید

1. Download a template

روی دکمه دانلود هر قالب بزنید و فایل HTML را ذخیره کنید. هر قالب در یک فایل مستقل است.

Click download on any template and save the HTML file. Each template is a single self-contained file.

۲. محتوا را ویرایش کنید

2. Edit the content

فایل را در VS Code یا هر ادیتوری باز کنید و اطلاعات شخصی خودتان را جایگزین کنید. تمام CSS و JS داخل همان فایل است.

Open in VS Code or any editor and replace the placeholder content. All CSS and JS are inside the same file.

۳. آپلود کنید

3. Upload

فایل PDF رزومه را در پوشه assets بگذارید و فایل HTML را روی هر هاستی آپلود کنید. تمام!

Put the PDF resume in assets folder and upload the HTML file to any host. Done!

سوالات FAQ

سوالات متداول Frequently asked questions

آیا استفاده از این قالب‌ها رایگان است؟ Are these templates free to use?
بله، تمام ۶ قالب کاملاً رایگان هستند و می‌توانید برای رزومه شخصی خودتان استفاده کنید. فقط کدها را ویرایش کنید و اطلاعات خودتان را جایگزین کنید. Yes, all 6 templates are completely free to use for your personal resume. Just edit the code and replace the placeholder content.
آیا به دانش برنامه‌نویسی نیاز دارم؟ Do I need coding knowledge?
برای استفاده پایه، فقط باید متن‌ها را در فایل HTML جایگزین کنید که کار ساده‌ای است. برای تغییرات ساختاری یا اضافه کردن بخش جدید، آشنایی با HTML/CSS مفید است. For basic use, you just need to replace text in the HTML file which is simple. For structural changes or adding new sections, HTML/CSS familiarity helps.
چطور زبان را تغییر دهم؟ How do I switch language?
روی دکمه «EN» یا «فا» در گوشه بالای صفحه کلیک کنید. زبان انتخابی در مرورگر شما ذخیره می‌شود و دفعه بعد هم اعمال می‌شود. Click the "EN" or "فا" button in the top corner. Your language choice is saved in the browser and persists next time.
چطور رزومه PDF را جایگزین کنم؟ How do I replace the PDF resume?
یک پوشه با نام «assets» بسازید و فایل‌های PDF خود را با نام‌های «resume-fa.pdf» و «resume-en.pdf» در آن قرار دهید. دکمه PDF به صورت خودکار فایل را بر اساس زبان فعلی بارگذاری می‌کند. Create an "assets" folder and place your PDF files named "resume-fa.pdf" and "resume-en.pdf" inside. The PDF button automatically loads the correct file based on current language.
آیا می‌توانم قالب‌ها را برای مشتری بفروشم؟ Can I resell the templates to clients?
بله، می‌توانید برای مشتری شخصی‌سازی کنید و تحویل دهید. اما فروش مجدد یا توزیع خود قالب به عنوان یک محصول جداگانه مجاز نیست. Yes, you can customize and deliver to a client. But reselling or distributing the template itself as a standalone product is not allowed.
